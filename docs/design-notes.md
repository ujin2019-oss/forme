# FORME. 디자인과 검수 기록

최초 제작 기록입니다. 이후 UI/UX 개선 사항과 최신 검수 범위는 [UI/UX 개선 결과](ui-ux-review.md)를 참고하세요.

## 1. 레퍼런스 접근 결과

2026-11-09 기준 제공된 [MONO ARCHIVE 레퍼런스](https://ujin2019-oss.github.io/cafe1/01_mono-archive/index.html)에 웹 도구로 두 차례 접근을 시도했으나 접근할 수 없다는 결과를 받았습니다. PowerShell 직접 요청도 네트워크 소켓 접근 제한으로 실패했습니다.

따라서 다음 항목은 직접 확인할 수 없었습니다: 실제 디자인 콘셉트, 레이아웃·그리드, 폰트·여백, 히어로 구성, 이미지·텍스트 배치, 스크롤 모션, 상품·스토리 콘텐츠, PC·모바일 반응형 방식. 확인하지 못한 특성을 레퍼런스의 실제 특성으로 기술하지 않았습니다.

아래 방향은 사용자가 제공한 ‘패션 에디토리얼 감성’과 FORME. 브랜드 가이드의 독자적인 해석입니다.

## 2. 디자인 시스템

- 콘셉트: 빛과 그림자, 건축적인 형태, 일상에 놓이는 스킨케어 오브제
- 팔레트: Warm Ivory #F1EEE7 / Charcoal #262722 중심, Taupe #B8B0A4 / Stone #77766D / Bronze #A18B77 보조
- 폰트: Inter 가변 폰트와 Pretendard 가변 폰트, 로컬 파일과 OFL 라이선스 포함
- 1440px 기준, 최대 콘텐츠 너비 1400px, 유동적인 좌우 여백
- 6:5, 7:4, 5:6 비례로 12컬럼의 비대칭 화보 구성. 제품은 4열, 저널은 3열
- 밝은 페이지에서 차콜 제형 화보, 다시 밝은 루틴, 따뜻한 캠페인, 차콜 클로징으로 이어지는 명암의 리듬
- 브론즈는 포커스와 링크 호버에만 절제해서 사용

## 3. 콘텐츠와 레이아웃

1. Hero: 전체 뷰포트 높이의 제품 화보, 왼쪽 대형 슬로건, Discover CTA
2. Philosophy: 왼쪽 석재·제품 화보, 오른쪽 한·영 철학, 비대칭 여백
3. Essentials: 통일된 용기와 조명의 제품 4종, 가격·용량·한글 설명, 상세 모달
4. Form & Texture: 차콜 배경, 대형 세럼 이미지와 아래로 내려 배치한 크림 매크로
5. Ritual: 루틴 제품 화보와 네 단계 아코디언, 단계별 제품 상세 연결
6. Campaign: 자연스러운 피부 질감의 모델 이미지 두 장, 제품과 피부를 연결한 화보
7. Formula: 소재 연구 이미지, 보습·균형·사용감 설계 방향, 정보 공개 안내
8. Journal: 이미지 3개와 실제 읽을 수 있는 한국어 에디토리얼 3편
9. Closing & Footer: 슬로건과 대형 워드마크, 메뉴·상담·SNS·사업자 안내와 가상 브랜드 고지

## 4. 반응형과 접근성 구현

1100px 이하에서 비례·글자 크기를 조정합니다. 767px 이하에서 모바일 메뉴, 단일열 철학·텍스처·루틴·캠페인·포뮬러·저널, 2열 제품 카드로 전환합니다. 374px 이하의 좁은 화면도 별도로 보완했습니다. 모바일 히어로는 이미지 크롭과 명도를 조정해 카피 가독성을 우선했습니다.

본문 바로가기, 의미 있는 alt, 키보드 포커스 스타일, 최소 44px의 주 조작 영역, 메뉴 Escape와 포커스 순환, 배경 inert, 네이티브 dialog 포커스 제한 및 닫은 뒤 원래 버튼으로 복귀를 구현했습니다. 스크립트가 없으면 주요 콘텐츠는 처음부터 표시되고, IntersectionObserver 사용 가능 시에만 등장 모션을 활성화합니다. prefers-reduced-motion에서는 모션을 제거합니다.

## 5. 검수 기록과 한계

완료: 파일 구조 확인, 기존 파일 보존, 이미지 15개 생성·저장·연결 및 전체 원본의 시각 확인, JPEG 웹 최적화, 폰트 로컬화, JavaScript 구문 검사, 정적 참조 검사, 배포 폴더 생성, 로컬 홈페이지·검수 화면 HTTP 200 응답 확인.

정적 검사 결과: `PASS: 9 sections, 26 unique IDs, anchors and ARIA references, local assets, 15 complete JPEGs (2.75 MiB), font files, demo disclosure, reduced-motion hooks.`

브라우저 검수 제한: CUA 브라우저 호스트가 비활성 상태였고, 네이티브 Chrome 연결은 현재 URL을 확인하지 못해 정책상 중단됐습니다. 우회하는 브라우저 제어를 사용하지 않았습니다. 실제 렌더링과 상호작용은 미검증 상태입니다.

남은 검수: `docs/review.html`의 세 뷰포트에서 모든 섹션을 시각 확인하고, 실제 브라우저에서 Tab / Shift+Tab / Escape, 모바일 메뉴, 모달 스크롤, 앵커 이동, 확대 200%, 모션 감소 설정을 확인해야 합니다. 정적 검사는 시각·접근성·실기기 검수를 대체하지 않습니다.
