## 제품 탐색과 연결 상태

4종의 제품명·용량·가격·소개·사용 제안은 기존 데이터와 동일합니다. 원본 ZIP과 제품 데이터 블록을 비교해 변경이 없음을 확인했습니다. 가격은 계속 콘셉트 가격이며, 실제 판매 정보로 전환하지 않았습니다.

전체 카드에서 기존 상세 모달을 열 수 있고 Tab으로는 카드당 한 번만 이동합니다. 포커스는 카드 전체에 표시되며, 모달을 닫으면 해당 버튼으로 돌아옵니다. 별도 상세페이지와 주문 기능은 여전히 연결이 필요한 항목입니다.

## 루틴 연결 및 비동기 처리

| 단계 | 연결 제품 / 기존 이미지 |
|---|---|
| Cleanse | Daily Cleanser / cleanser.jpg |
| Prepare | Essence Toner / toner.jpg |
| Balance | Balance Serum / serum.jpg |
| Protect | Barrier Cream / cream.jpg |

HTML의 `data-ritual-product`를 사진·캡션·본문 상세 링크의 연결 기준으로 사용합니다. aria-expanded, aria-controls 및 이름이 연결된 region을 적용했습니다. Enter / Space로 선택하고 방향키·Home·End로 단계 버튼을 탐색합니다. 모션 감소 설정에서는 페이드를 생략합니다.

이미지가 디코딩된 뒤 전환하며 요청 번호로 오래된 결과를 무시합니다. 연속 선택 시 앞선 페이드를 취소하고 마지막 이미지 하나만 남깁니다. 이미지 로딩 실패 시 실제 표시 중인 단계로 복구합니다. 그림 영역 높이를 고정해 전환 중 레이아웃 이동을 막았습니다. 기존 그룹 화보 ritual.jpg는 파일로 보존했습니다.

## 미검증·추가 확인 항목

브라우저 연결 호스트가 없고 기존 Edge 앱 접근 승인이 시간 초과되어 실제 브라우저 조작·스크린샷 비교를 하지 못했습니다. CSS 파싱과 DOM 시뮬레이션은 실제 렌더링을 검증하지 않습니다.

1440 / 1024 / 768 / 390 / 360px의 가로 넘침, 실제 글자 줄바꿈, 크롭, 대비, 터치 영역, 네이티브 dialog 포커스·Escape, 브라우저별 스크롤 및 섹션 여백은 실제 화면 검수가 필요합니다. `http://127.0.0.1:5500/forme/docs/review.html`은 이 다섯 뷰포트에서 열었을 때 자동 검사와 섹션별 화면을 제공합니다. 이번 작업에서 해당 페이지를 브라우저로 실행했다고 주장하지 않습니다.

확정된 성분·효능·인증·사업자 정보와 실제 제품 상세 URL, 커머스 백엔드, 공식 고객센터·SNS 주소는 제공되지 않아 추가하지 않았습니다. 기존 안내를 유지했습니다. Git commit / push와 외부 업로드·배포는 진행하지 않았습니다.
