# FORME 최종 모바일 UI/UX 개선 — 2026-11-10

현재 로컬 소스를 기준으로 개선했습니다. Git commit, push, 업로드, 배포는 하지 않았습니다. 공개 URL은 웹 조회 도구로 열리지 않아 배포본과 로컬의 일치 여부를 확인하지 못했습니다.

## 기존 구조와 동작

- Hero → Philosophy → Essentials → Texture → Ritual → Campaign → Formula → Journal → Closing의 9개 섹션입니다.
- Inter / Pretendard, 아이보리·브라운·차콜 및 기존 컬러 변수를 유지합니다.
- 반응형 기준은 1600px 이상, 1100px 이하, 767px 이하, 374px 이하입니다. 768px부터 PC·태블릿 구성을 사용합니다.
- 상품은 `js/main.js`의 `products` 객체, Journal은 `articles` 객체에 연결됩니다. 독립 상세 URL은 없으며 카드 전체 영역을 덮는 단일 버튼이 기존 dialog를 엽니다. 상세 모달과 검색을 유지하고 가짜 페이지를 만들지 않았습니다.
- Ritual은 Cleanse→cleanser, Prepare→toner, Balance→serum, Protect→cream입니다. 단일 펼침, 이미지 사전 디코딩·캐시, 요청 순서 보호, 페이드, 모션 감소 설정 및 방향키·Home·End 탐색을 유지합니다. Enter·Space는 네이티브 button 동작을 사용합니다.
- 모바일 내비게이션은 상단 로고·아이콘과 하단 BRAND / SHOP / COMMUNITY 링크입니다. 별도 햄버거 메뉴나 히어로 슬라이더는 없습니다.

Ritual 설명은 기존 문단을 한 곳에서 읽어 요약과 동기화합니다. 새 제품 정보나 효능은 추가하지 않았으며 Protect의 아침 자외선 차단제 안내도 유지했습니다. 이미지 영역과 요약의 최소 높이를 확보하여 전환 시 높이 변화를 줄였습니다. 로딩 중에는 현재 선택을 유지하고, 전환 중 후속 로딩이 실패해도 표시 제품에 맞는 상태와 이미지 하나로 복구합니다. `aria-expanded`, `aria-controls`, `aria-live`, `aria-busy`를 연결했습니다.

## 수정 파일

- `index.html`: 모바일 히어로 source 크기 명시, Ritual 요약과 두 단계 문장 정리
- `css/style.css`: PC에서 모바일 전용 요약을 숨기는 규칙만 추가
- `css/responsive.css`: 모바일 상품·Ritual·Campaign·Formula·Journal·Hero와 터치 영역 조정
- `js/main.js`: Ritual 이미지·설명 동기화, 페이드 중 로딩 실패 복구
- `docs/check-interactions.mjs`: 로딩 중 상태 유지, 요약 일치, 재선택, 페이드 중 실패 회귀 검사
- `docs/check-responsive.mjs`: 7개 폭의 적용 CSS 선언 검사. 브라우저 레이아웃 엔진은 아님
- `docs/review.html`: 요청한 7개 실제 iframe 크기와 요약·그리드·터치 영역 검사 준비. 오래된 contain 기반 히어로 판정 제거
- 이 보고서, 기존 검수 기록의 최신 보고서 링크 및 README 갱신
- `dist/index.html`, `dist/css/style.css`, `dist/css/responsive.css`, `dist/js/main.js`: 최신 소스로 빌드

## 남은 확인 사항

브라우저 접근 호스트가 연결되지 않아 실제 렌더링과 수정 전후 스크린샷 비교는 수행하지 못했습니다. CSS 선언·DOM 검사는 가로 스크롤, 실제 글자 줄바꿈·잘림, 제품과 카피 겹침, 모델 크롭, 명암 대비, 이미지 로딩 시 실제 레이아웃 이동, 네이티브 Enter·Space·Escape와 스크린리더 읽기, 터치 기기 동작을 증명하지 않습니다.

로컬에서 `node serve.mjs` 실행 후 `http://127.0.0.1:4173/docs/review.html`을 열면 7개 화면 폭의 검사와 섹션별 미리보기를 확인할 수 있습니다. 추가로 360×640의 짧은 화면, 모바일 가로 화면, 텍스트 확대, Safari의 이미지 마스크와 `svh` 처리도 확인해야 합니다. 이 검수 페이지는 이번 작업에서 실제 실행 완료로 보고하지 않습니다.

독립 상품 URL, 실제 구매 기능, 확정된 성분·효능 정보는 제공되지 않아 기존 콘셉트 모달과 안내를 유지했습니다.
